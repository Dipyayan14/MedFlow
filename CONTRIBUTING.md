# Contributing to MedFlow

Thanks for helping out. This is a learning project, and all skill levels are welcome.

## Reporting a bug
Open an issue and include:
- What you did and what you expected
- What actually happened, with any error text or a screenshot
- Your OS and your Flutter and PHP versions

## Suggesting a feature
Open an issue describing the problem it solves. Issues labeled `good first issue` are a good place to start.

## Opening a pull request
1. Fork the repo and create a branch: `git checkout -b my-change`
2. Keep changes small and focused on one thing.
3. Backend: run `php artisan test`. Frontend: run `flutter analyze`.
4. Describe what you changed and why in the pull request.

## Ground rules
- Never commit `.env` files, keys, tokens, or real patient or staff data.
- Don't add compliance or certification claims (HIPAA, NABH, and so on) to the UI or docs.
- Be kind and constructive in reviews and discussions.
